# UX-001 - Documentation Module Home

## Objective

This screen is the entry point to the Documentation module. It must be simple, clean, and only help the advisor decide what to do next.

## User question answered

What do I want to do in Documentation?

## Required components

- Header
- Main action card
- Module title

## Header requirements

The header must follow the existing CRELEALTAD app pattern:

- CRELEALTAD logo
- Smaller CRELEALTAD text
- User name clearly visible
- User avatar or initials
- Current work week
- Module name: DOCUMENTACIÓN
- No hamburger menu

## Main actions

Only these three actions are allowed:

- Renovación
- Grupo nuevo
- Mis expedientes

## Forbidden elements

Do not include:

- Search button
- Hamburger menu
- Last expediente
- Charts
- Statistics
- Notifications
- Extra menu options

## Navigation

- Renovación opens the renewal flow.
- Grupo nuevo opens the new group flow.
- Mis expedientes opens UX-002.

## UX rules

- Large touch targets.
- High readability.
- Minimal text.
- Designed for advisors around 55 years old.
- Usable in the field and with one hand.

## Acceptance criteria

- The advisor understands the screen in less than 3 seconds.
- There are only three primary actions.
- The screen does not duplicate search functionality.
- The header always identifies the logged-in user.
- The screen follows the CRELEALTAD Design System.
