## Contradicciones documentadas

- C-001: Estados simplificados en prototipo versus catalogo constitucional.
Tratamiento vigente: el catalogo constitucional prevalece; la implementacion actual se documenta como parcial.

- C-002: Tipos documentales hardcoded versus politicas parametrizadas.
Tratamiento vigente: la parametrizacion prevalece; el hardcode actual se conserva solo como semilla temporal.

- C-003: Solicitud en API y mobile sin tabla dedicada en schema.
Estado actualizado 2026-08-13: RESUELTA. PostgreSQL contiene `solicitudes`, siete tablas hijas y la vista `solicitudes_completo`; la API usa repositorios TypeORM.

- C-004: Estados tecnicos de SQL como draft, active y pending versus estados funcionales de negocio.
Tratamiento vigente: los defaults SQL no sustituyen la semantica funcional del sistema.

- C-005: Autenticacion JWT disponible versus autorizacion por rol/accion ausente.
Tratamiento vigente: contradiccion tecnica resuelta; el guard global aplica modulo/accion y falla cerrado. Permanece abierta la aprobacion de la matriz funcional definitiva.

- C-006: Permisos JSONB presentes versus navegacion y acciones no filtradas.
Tratamiento vigente: contradiccion tecnica resuelta; API y mobile consumen permisos efectivos y `ASESOR` aplica además alcance por responsable en el recorrido activo. Permanece abierto el alcance por sucursal/zona y los demas roles.

- C-007: Captura local con AsyncStorage versus operacion offline completa.
Tratamiento vigente: se reconoce persistencia local parcial; no se declara offline-first hasta implementar cola, reintentos, idempotencia, sincronizacion y reconciliacion.

- C-008: Login implementado por correo versus abreviatura aprobada para asesores.
Tratamiento vigente: contradiccion resuelta; la abreviatura es el contrato implementado y probado en PostgreSQL, API, JWT y mobile para asesores.

- C-009: Principio de menor privilegio versus acceso amplio temporal durante desarrollo.
Tratamiento vigente: DEC-023 es una excepcion funcional temporal para usuarios activos y modulos ejecutables. Las rutas conservan JWT y guard de permisos, los modulos no implementados siguen bloqueados y antes de produccion debe aprobarse y aplicarse la matriz rol-modulo-accion definitiva.

- C-010: RN-007 declara que grupo y credito nacen tras desembolso, mientras el flujo operativo vigente crea la identidad del grupo al iniciar Documentacion y reserva ciclo/credito para el desembolso.
Tratamiento vigente: ABIERTA. La auditoria no modifico la regla ni el flujo. Direccion debe precisar si RN-007 usa "grupo" como grupo crediticio desembolsado o si debe corregirse para distinguir la identidad operativa previa.
