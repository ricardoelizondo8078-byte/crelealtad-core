# Carpeta `docs/project` reorganizada

Esta carpeta está preparada para reemplazar completamente la carpeta actual `docs/project/` del repositorio CRELEALTAD CORE.

## Instalación

1. Cierra VS Code o detén procesos que estén usando el proyecto.
2. Haz una copia de seguridad de `docs/project/` actual.
3. Elimina únicamente la carpeta `docs/project/` actual.
4. Copia esta carpeta `project` dentro de `docs/`.
5. Confirma que exista `docs/project/00_START_HERE.md`.
6. En la siguiente sesión de Codex usa el prompt mínimo incluido en ese archivo.

No reemplaces las demás carpetas de `docs/` ni el código de `apps/`.
