# 10 UI UX Standards - Estandares de Interfaz

Version: 1.0.0
Estado: Vigente

## Perfil de uso

Diseno centrado en asesora en campo: lectura rapida, accion clara, baja friccion.

## Principios UX

1. Mostrar primero pendientes.
2. Reducir carga cognitiva.
3. Un objetivo principal por pantalla.
4. Lenguaje operativo, no tecnico.
5. Botones amplios y legibles.

## Layout

- Espaciado consistente por tokens.
- Jerarquia tipografica clara.
- Acciones primarias visibles.
- Acciones secundarias no compiten visualmente.

## Componentes

- Botones primarios y secundarios.
- Cards con resumen operativo.
- Headers con contexto de modulo y usuario.
- Mensajes de estado y error accionables.

## Validaciones

- En linea, sin interrumpir captura innecesaria.
- Mensajes concretos: que fallo y como corregir.

## Errores

- No usar mensajes genericos.
- Siempre explicar siguiente paso.

## Responsive y accesibilidad

- Funcional en telefonos de gama media.
- Contraste suficiente.
- Tamaños tactiles adecuados.
- Evitar sobrecarga de texto.

## Decision ante contradicciones UX

- Si hay diferencia entre boceto y operacion real, prevalece la operacion.
- Si hay diferencia entre vista bonita y claridad operativa, prevalece claridad.
